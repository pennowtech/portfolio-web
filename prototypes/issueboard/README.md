# Issueboard layout prototype

Open [`index.html`](index.html) directly in a browser. It is a dependency-free, responsive, clickable product-layout artifact and does not connect to production services.

## Included screens

- Overview dashboard
- Ranked backlog and sprint planning
- Active sprint Kanban board
- Calendar
- Reports
- Full issue detail with checklist, subtasks, attachments, and activity
- Project list
- Project and workflow settings
- Integrations, storage capacity, and provider-health view
- Create-issue modal with browser-compression preview
- Mobile navigation and responsive alternatives to desktop layouts

Use the left navigation to change screens. Select **Create issue** to inspect the creation modal, and select the `PORT-66` board card to open the issue detail layout.

## Prototype boundaries

- All data is illustrative and stays inside the static HTML.
- Buttons demonstrate navigation and layout intent only, not persistence.
- This artifact establishes information architecture and visual hierarchy before the Next.js components and Supabase schema are implemented.
- GitHub, Jira, Trello, Notion, Slack, and Supabase are not contacted by the prototype.
