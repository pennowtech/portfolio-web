# AI configuration UX artefacts

Open [`index.html`](index.html) directly in a browser.

These five interactive concepts preserve the current implementation: Groq, OpenAI, Anthropic, Ollama, Mistral, Gemini, and Built-in Rules each keep independent credentials and model choices; one provider is active globally; model lists can be fetched; exact model IDs remain available as an escape hatch; connection testing is separate from credential entry; and personas, temperature, and the system prompt are shared writing settings.

1. **Connection Workbench** — recommended; provider navigation, focused configuration, and activation readiness in one view.
2. **Guided Setup** — a first-run wizard based on speed, local privacy, or zero-setup needs.
3. **Provider Switchboard** — a fleet-style status table for people who maintain several providers.
4. **Impact Preview** — explains configuration through Book Autofill, cover recognition, and AI Rephrase outcomes.
5. **Configuration Recipe** — a searchable, keyboard-friendly expert workflow with progressive disclosure.

The demos simulate interactions and never persist credentials or configuration.
